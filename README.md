# Smart Student Management System (C++)

A feature-rich console-based Student Management System developed in C++ that simulates a real-world academic administration portal. The project demonstrates Object-Oriented Programming, file handling, arrays, functions, vectors, sorting, searching, authentication, and academic analytics.

## Features

- Admin login authentication
- Add new student records
- View all students in table format
- Search students by roll number or name
- Update student details
- Update marks for 5 subjects
- Track attendance percentage
- Calculate GPA automatically
- Generate student report card
- Delete student records
- Generate topper list
- Academic analytics report
- Persistent data storage using file handling

## Concepts Used

- C++ Programming
- Object-Oriented Programming
- Classes and Objects
- Encapsulation
- File Handling

```bash

./student_management
```

### On Windows

